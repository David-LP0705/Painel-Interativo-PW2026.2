# 🖥️ Painel Interativo com JavaScript

Projeto desenvolvido como parte das atividades práticas da disciplina de **Programação para Web**, com o objetivo de praticar a manipulação do DOM e a interação do usuário com a página através do JavaScript puro (Vanilla JS).

---

## 🚀 Funcionalidades da Página

- **Mensagem Dinâmica:** O texto inicial da página é inserido/modificado via JavaScript assim que o script é carregado.
- **Captura de Entrada (Input):** Lê o nome digitado pelo usuário em um campo de texto e valida se o campo está vazio.
- **Saudação Personalizada:** Exibe uma mensagem de boas-vindas com o nome informado ou um aviso de erro caso o campo esteja em branco.
- **Contador de Cliques:** Conta quantas vezes o botão de envio foi acionado com sucesso, mantendo o estado de forma global.
- **Alternador de Tema (Dark/Light Mode):** Altera as cores de fundo e do texto do painel dinamicamente utilizando propriedades de estilo (`style.backgroundColor` e `style.color`).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura base da página web.
- **CSS3 (Inline/Dinâmico):** Estilização inicial e controle de temas via JavaScript.
- **JavaScript (ES6):** Lógica de programação, seleção de elementos (`document.getElementById`), funções, condicionais e manipulação de eventos de clique.
